# Demo

[FastAPI 0.115.0, mapped](https://ngavrish.github.io/where-are-we/demo/fastapi/)
is what this tool writes for a repository it has never seen before: one tree
walk, no model involved. The live page is served from the `gh-pages` branch,
not this `docs/` directory; its source is built by
[`docs/demo/build.sh`](demo/build.sh), and
[`docs/demo/fastapi/README.md`](demo/fastapi/README.md) has the tag, the date
and the exact command that produced it.
